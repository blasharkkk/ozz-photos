# 纸云相册 · Paper Cloud

一片悬在破碎镜面上方的纸照片云。照片像棉纸一样挂在细线上漂浮，底下是破碎的镜面，
天花板投下摇曳的光斑。纯 WebGL2 手写渲染，无框架、无构建步骤。

## 在线体验

- 公网：https://paper-cloud.app.workbuddy.host/
- 本地运行：任意静态服务器，例如 `python -m http.server 8123`，然后打开 `http://127.0.0.1:8123/index.html`

## 特性

**3D 场景**
- 拖动环视、滚轮/双指缩放、点击照片聚焦、方向键切换、Esc 退回全景
- 鼠标掠过照片与丝线会有柔和的力场扰动；按住照片可下拉牵引，松手弹簧回弹
- 聚焦时其余纸片柔和淡出，贴近视线才碎成纸屑

**照片编辑器（放进云之前）**
- 自由裁剪 + 常用比例锁定（1:1、4:3、3:4、3:2、2:3、16:9、9:16）
- 相纸系统：经典 / 纯色（色相+饱和度滑杆）/ 涂鸦（38 种手绘图形）/ 镭射
- 相框：拍立得（下宽）/ 等边 / 无相框，涂鸦系列另有窄边·等边·宽边三套固定模板

**照片背面创作**
- 5 支画笔：铅笔 / 圆珠笔 / 油性记号笔（不透明覆盖）/ 喷枪 / 橡皮擦
- 文本框对象：可拖动、自由等比缩放、旋转（Shift 吸附 15°）、双击改字
- 手写字体（马善政 / 志莽行 / Caveat）**按需加载**，不阻塞首屏
- 撤销 20 步、清空画布

**3D 背面呈现**
- 全景中有背面的照片，部分纸片背面朝外，正反混飘
- 聚焦单张可 3D 翻转看背面；双击照片即可重新进入编辑（完整还原上次的裁剪/相纸/文本）

**数据存储**
- 每位访客的照片保存在**自己的浏览器 IndexedDB**，互不可见
- IndexedDB 为主 + localStorage 兜底双写，容量不足时明确提示

## 目录结构

```
index.html      页面骨架、编辑器 DOM
main.js         全部逻辑：WebGL2 渲染、动力学、相纸/编辑器/背面创作、持久化
style.css       样式（含深色下拉、画布缩放、文本选中框）
photos.json     示例照片清单
assets/photos/  30 张示例照片
assets/backs/   30 张预置背面（手写文字 + 涂鸦）
assets/fonts/   3 款 SIL OFL 开源手写字体
```

## 技术要点

- 纯 WebGL2 + GLSL，无任何运行时依赖
- 照片存进 `TEXTURE_2D_ARRAY`，正反两层纹理按纸片朝向采样
- 每张照片用**独立确定性随机种子**决定位置与取景，给某张照片加背面/裁剪都不会扰动其它照片
- 翻转 180° 后需水平镜像 UV，背面文字才正向可读；背面朝外的纸片不镜像（用 per-instance 标记区分）
